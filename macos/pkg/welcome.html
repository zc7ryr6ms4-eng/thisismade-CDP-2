thisismade cdp-2

Ein Musikplayer, der wie ein professionelles CD-Deck funktioniert: drehende Disc, rotes LED-Display, Tempo-Fader mit Key Lock, Memory-Cues A/B/C, Shuttle, Ziffernblock, Wiederholen und Zufall.

Hinweis zur Installation: Die App wird während der Installation auf deinem Mac aus dem Quellcode erstellt. Falls Apples kostenlose Command Line Tools noch fehlen, werden sie automatisch mit installiert. Das kann beim ersten Mal 5–15 Minuten dauern (Internetverbindung nötig) – bitte das Fenster so lange offen lassen.

Voraussetzung: macOS 13 Ventura oder neuer, Apple Silicon oder Intel.
